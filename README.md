# 🌸 Bloom — Premium To-Do Web Application

Bloom is a modern and visually refreshing To-Do Web Application built using **HTML, CSS, and JavaScript**.

Designed with a premium productivity-inspired UI, Bloom helps users organize tasks, manage priorities, track progress, and stay focused through an elegant and interactive experience.

## ✨ Features

### Task Management

* Add, edit, delete, and duplicate tasks
* Mark tasks as completed
* Organize tasks using categories
* Set priorities (High / Medium / Low)
* Add due dates and due times
* Track task status

### Dashboard & Productivity

* Live task statistics
* Circular progress tracker
* Daily productivity overview
* Streak tracking
* Pomodoro timer
* Focus mode

### Smart Organization

* Search tasks instantly
* Filter by:

  * Category
  * Status
  * Priority
* Sort tasks:

  * Due Date
  * Priority
  * Creation Date
  * Alphabetically

### Calendar View

* Monthly interactive calendar
* View scheduled tasks by date

### User Experience

* Refreshing Mint Green UI
* Glassmorphism effects
* Dark mode support
* Smooth animations
* Fully responsive design

### Data Storage

* Local Storage support
* Export tasks as JSON
* Import tasks from JSON
